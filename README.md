# 年卡打卡微信小程序

## 在微信开发者工具中打开

1. 安装并打开微信开发者工具，选择“导入项目”，项目目录选本仓库根目录。
2. 在开发者工具项目设置中填写你自己的小程序 AppID。`project.config.json` 中的 AppID 是占位值；本地替换即可，不要提交真实 AppID。
3. 在 `miniprogram/app.js` 的 `CLOUD_ENV_ID` 填入你自己的云开发环境 ID。不要把真实环境 ID 写入公开仓库。
4. 在开发者工具中启用云开发，并确认当前环境与 `CLOUD_ENV_ID` 相同。

## 云数据库与云函数

在该云环境中新建 `userSettings` 和 `visits` 集合。两个集合的客户端读写权限都设为关闭/仅管理端可访问；小程序通过云函数访问数据，不应向客户端开放集合权限。

在 `cloudfunctions/tracker` 上右键选择“上传并部署：云端安装依赖”。函数依赖由目录中的 `package.json` 声明（`wx-server-sdk`）。云函数使用当前云环境，并通过微信身份隔离用户数据。

云函数会按 `owner` 与 `generation` 查询 `visits`，并按 `_id` 排序分页。若云数据库提示缺少复合索引，请按提示建立 `owner`、`generation`、`_id` 字段的升序复合索引；如该环境支持查询自动创建索引，则无需额外配置。`userSettings` 使用固定文档 ID 读取，不需要额外查询索引。

## 数据行为与迁移

- 有网络且云端请求成功时，云端状态是当前数据来源；更新操作在云函数中完成，成功返回后才更新界面和本机缓存。
- 网络不可用或云请求失败时，小程序可提示查看本机缓存。该缓存无法证明属于当前微信账号，界面会标记“账号未验证”，并以只读方式显示；写入和导入都会被阻止，直到成功重新连接云端。
- “导出 JSON”会生成包含 `app`、`version`、`exportedAt`、`settings`、`visits` 的备份文件，并调用微信文件分享面板。接收端可以保存文件或转发给自己。此分享流程要求基础库 2.7.0 或更高版本（`wx.shareFileMessage`）。
- “导入 JSON”通过微信聊天文件选择器读取一个 JSON 文件，校验设置和记录，并先展示记录数与替换警告。确认后会替换当前已验证微信账号的云端年卡设置和全部打卡记录；取消不会写入任何数据。
- 可将网站导出的 JSON 备份导入小程序。网站本地数据不会自动同步到小程序；需要先在网站导出，再在小程序显式导入。

文件选择使用 `wx.chooseMessageFile`，要求基础库 2.5.0 或更高版本。使用支持以上 API 的微信客户端和开发者工具进行迁移。

## 平台要求

本项目面向微信小程序，需要微信开发者工具、小程序 AppID、启用的微信云开发环境以及可用的云函数和云数据库。没有云开发配置时，小程序不能验证账号或写入云端数据。
